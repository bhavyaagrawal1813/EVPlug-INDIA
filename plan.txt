# 3. EXISTING EVPLUG APP — FULL FUNCTIONAL DESCRIPTION

EVPlug is an EV charging-station application.

The main purpose is to allow an EV user to:

1. Create/login to an account.
2. Set up their EV/vehicle.
3. View nearby EV charging stations.
4. View charging stations on a map.
5. Find the nearest charging station.
6. Save charging stations.
7. Add community charging stations.
8. View station information.
9. Use an AI assistant for EV charging/trip recommendations.
10. Use the vehicle's estimated range and current battery percentage to determine whether a charging station may be reachable.
11. Eventually support more advanced charging-station intelligence.

The app should feel like a serious production EV application rather than a demo.
